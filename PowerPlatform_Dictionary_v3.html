データのエクスポート

    

      
現在の全データ（収録項目＋自作項目＋メモ＋お気に入り）を書き出します。

      

        
      

    

    

      
      
    

  






  

    
使い方

    

      
1画面で大きく見る

      
    
        
  • カードの ⤢ ボタン、またはタイトルをクリックすると、その項目だけを全画面で表示します
    • 
        
  • 詳細ビューでは ◀ 前 / 次 ▶（キーボードの ← →）で、絞り込み中の項目を順に読めます
    • 
        
  • 右上の 小 / 中 / 大 / 特大 で本文とコードの文字サイズを変更できます（設定は保存されます）
    • 
        
  • 詳細ビュー内の 🖨 で、その項目だけを印刷できます
    • 
        
  • 下部の「関連項目」から、同じ分類・同じタグの項目へジャンプできます
    • 
        
  • 一覧側は 表示：自動 / 広め / 1列 で列数を切り替えられます（設定は保存されます）
    • 
      

      
基本操作

      
    
        
  • 製品切替（Power Apps / Power Automate）→ 機能別タブで絞り込み
    • 
        
  • 検索は「名称・構文・説明・コード・タグ・自分のメモ」を全文AND検索。該当箇所はハイライト
    • 
        
  • コード右上の ⧉ コピー でクリップボードへ
    • 
        
  • コードに {{…}} がある項目は ⚙ 差替コピー が出ます。リスト名・列名を入力してからコピーできます
    • 
        
  • カード下部の メモ欄 は入力後「保存」でブラウザに保存
    • 
        
  • ★ お気に入り／✎ 編集（収録項目も編集可）
    • 
      

      
出典バッジ

      
    
        
  • ノートOneNote「Power Apps / PowerAutomate」セクションの内容を原文どおり収録
    • 
        
  • 社内資料社内のWord/Excel資料から採録（資料名をカードに明記）
    • 
        
  • バッジなし＝一般公開情報ベースの基本リファレンス
    • 
      

      
ショートカット

      
    
        
  • /：検索へフォーカス
    • 
        
  • Enter（検索欄）：先頭の項目を1画面表示
    • 
        
  • ← →：詳細ビューで前／次の項目へ
    • 
        
  • Esc：詳細ビュー／モーダルを閉じる、検索クリア
    • 
        
  • Ctrl+S：エクスポート
    • 
      

      
データの保存場所と制約（重要）

      
    
        
  • メモ・お気に入り・自作項目はブラウザのlocalStorageに保存されます。PCやブラウザが変わると引き継がれません。
    • 
        
  • InPrivate／シークレットウィンドウ、ブラウザのキャッシュ削除で消えます。
    • 
        
  • 複数人で共有する場合は、定期的に JSONエクスポート → 共有フォルダ保存 → 各自インポート の運用、
            もしくは SharePoint リスト＋Power Apps への移行を検討してください。
